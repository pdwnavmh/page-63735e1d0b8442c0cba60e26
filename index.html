品牌简介

天航面向需要稳定跨境连接的个人与团队，运营天航机场节点网络，并配套主流加速器客户端。我们以森林绿所象征的稳健与克制为产品原则：把带宽、延迟和可用性做扎实，而不是堆砌无法兑现的口号。

服务覆盖普通线路与 IPLC 专线，订阅可一键导入 Clash 等客户端。官方身份仅以本站公布的套餐、操作说明与下载指引为准，请勿通过非官方渠道安装来路不明的安装包。

客户端选择

天航强调先选对客户端，再导入机场订阅。不同系统推荐如下，均支持通用订阅格式，便于在电脑与手机之间同步节点。

Windows / macOS

推荐 Clash Meta 内核图形客户端。导入订阅后开启系统代理并使用规则分流，适合作为主设备长期使用。

Android

推荐 Clash Meta for Android。授予 VPN 权限后更新订阅，可按应用分流，减少游戏或银行类应用误走代理。

iOS

常用 Shadowrocket、Stash 或 Quantumult X。通过 App Store 获取正版应用，粘贴天航订阅链接即可更新节点。

其他环境

Linux 可使用 clash.meta 或图形前端；路由器可刷入支持订阅的固件。团队版可申请定制路由，把办公网与个人设备分开调度。

请仅从正规应用商店或天航官网下载指引获取客户端。所谓“天航破解版”“一键连绿色包”均非官方来源。

操作说明

按下列纵向步骤完成首次连接，一般不超过十分钟。客户端选择正确后，后续只需更新订阅。

确认套餐与账号

在天航官网选定基础版、旗舰版或团队版并完成开通，进入用户中心复制订阅地址。订阅属于账号凭证，请勿公开传播。

选择并安装客户端

根据“客户端选择”安装对应软件。电脑优先 Clash 系图形界面，手机按系统选择成熟加速器，避免混用多个系统代理。

导入机场订阅

在客户端中选择从 URL 更新或订阅管理，粘贴天航订阅链接并更新节点列表。若提示失败，检查链接完整性后重试。

选择节点并连接

日常浏览选普通线路；看流媒体选解锁节点；玩游戏选 IPLC 或标注低延迟的专线。连接后查看延迟与出口是否符合预期。

规则分流与日常维护

开启规则模式，国内直连、跨境走代理，可节省套餐流量。节点异常时先更新订阅再切换线路；旗舰与团队用户可通过优先工单反馈。

常见问题

天航和普通单一出口 VPN 有什么不同？

天航以机场订阅提供多节点、可切换线路，并按流媒体解锁与游戏加速做了分类。你可以按场景选节点，而不是绑定一个固定出口。

如何下载天航可用的客户端？

电脑推荐 Clash Meta 图形客户端，安卓使用 Clash Meta for Android，苹果设备使用 Shadowrocket 等。详见本页客户端选择；安装后导入天航订阅即可，无需寻找破解安装包。

订阅链接在哪里复制？

开通套餐后登录天航用户中心，在仪表盘或订阅管理中复制通用订阅 URL。多数客户端支持一键导入 Clash 兼容格式。

设备数量超限会怎样？

同时在线超过套餐上限时，新会话可能无法建立或挤掉最早设备。基础版 3 台、旗舰版 5 台、团队版 20 台，请按实际终端数量选购。

流量包含哪些用途？

经代理产生的跨境流量计入套餐额度，国内直连通常不计。高清流媒体与大文件下载消耗较快，重度使用更适合旗舰版或团队版。

节点连不上如何排查？

先更新订阅并更换节点或协议，确认系统时间准确、客户端已获 VPN 权限，并关闭其他冲突的加速软件。仍失败时通过工单反馈，旗舰与团队用户优先处理。

年付与月付如何选择？

确定长期使用再选年付更划算：基础版按年付仅需 ¥150/年，旗舰版 ¥350/年，团队版 ¥850/年。具体开通与变更以用户中心规则为准。
